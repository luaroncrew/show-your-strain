# show-your-strain

Small Next.js app for the Show Your Strain sign-in landing page.

## Prerequisites

- Node.js 24+
- npm 11+

## Getting started

```bash
npm install
npm run dev
```

The app will start on the default Next.js development port.

## Validation

```bash
npm run lint
npm run build
```

## Notes

- Path aliases are configured so `@/*` resolves from the project root.
- The current app is a static landing page with a client-side sign-in form stub.
